# TwiceTwo

Мобильное приложение для знакомств через создание собственных мероприятий для нескольких пользователей, разработанное в сжатые сроки в рамках хакатона.

## Основной функционал
* Регистрация и заполнение анкеты пользователя.
* Просмотр карточек мероприятий других пользователей и система лайков.
* Создание своих карточек мероприятий.
* Навигация между основными экранами и работа с профилем.

## Стек технологий
* **Язык:** Kotlin
* **UI:** Jetpack Compose
* **Асинхронность:** Kotlin Coroutines
* **Архитектура:** MVVM, Clean Architecture
* **Сеть и данные:** Retrofit 2 / REST API, локальное хранение сессии
* **Сборка:** Gradle (Kotlin DSL, Version Catalog)
